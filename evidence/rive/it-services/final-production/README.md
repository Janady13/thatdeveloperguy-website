# IT Services final production evidence

This directory records the IT Services production animation build. The room uses the supplied `TDG_IT_SERVICES_ANIMATION_KIT` as source, keeps the approved static poster as the visual base, and layers only transparent production SVG/effect systems above it.

Key files:

- `source-inventory.json` — complete source-kit file inventory.
- `scene-graph.json` — semantic hierarchy and depth planes.
- `animation-inventory.json` — per-layer animation classification.
- `interaction-inventory.json` — interactive regions and state model.
- `coordinate-system.md` — canonical 1648x928 runtime math.
- `rive-architecture.md` — native Rive handoff and current .riv status.
- `mascot-anchor-map.json` — future character integration anchors only.
