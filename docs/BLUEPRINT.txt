THATDEVELOPERGUY — REACT + RIVE + SEO + AIO PRODUCTION BLUEPRINT
(owner's target architecture, supplied 2026-09-15; governs the build)
============================================================

PROJECT: thatdeveloperguy.com — company website and qualified-inquiry funnel for government organizations, prime contractors,
and small/medium businesses. Visual system: Lobby, IT Services room, Government Solutions room, Cybersecurity room, shared
Government Cyber Consultant mascot. One repository, one React website, one private TypeScript email-delivery service,
shared typed publication and animation modules. Native Rive assets require their own release approval.

01 NON-NEGOTIABLE BUILD RULES
A. The SEO/AIO library governs implementation; its instructions map to implemented files, outputs, verification steps, reviewers.
B. Consume the existing unified truth node; keep its Organization and Person identifiers; never equate brand, domain, person, legal org.
C. Public content works before animation loads: titles, descriptions, canonicals, headings, body, real links, JSON-LD are prerendered.
D. Rive enhances; a failed animation never removes navigation, content, contact details or the inquiry form.
E. Every public page has one canonical purpose and address.
F. Search providers receive the same approved meaning; no provider-specific hidden pages.
G. Private source material never becomes public (no repo root, artwork ZIPs, evidence, credentials, source maps, the library).
H. A successful animation is not a business action; only the backend reports provider acceptance, which is not mailbox delivery.

02 STACK: React, strict TypeScript, React Router Framework Mode (ssr: false, prerender: allPublishedPagePaths()), Vite, CSS tokens.
Unknown URLs receive an actual HTTP 404 (no universal 200 SPA fallback). Animation: official Rive React runtime
(@rive-app/react-webgl2 candidate), pinned runtime + matching WASM, browser-only boundary, poster first and kept on failure.
Backend: Node 24 LTS, Fastify, TypeScript, same-origin inquiry endpoint, direct email/SMTP, no database or submission archive.
Build/test: committed lockfile, npm ci, unit + production-build browser tests + real HTTP tests + accessibility review + release gates.
Hosting: BUBBLES — nginx serves the static site, proxies /api/ to the private Fastify service under systemd.

08 PUBLIC ENDPOINT OWNERSHIP: pages (prerender + static HTTP); /robots.txt, /sitemap.xml, /llms.txt (build-discovery, one owner);

09 INQUIRY AND MEASUREMENT: outcomes validation_failed | rate_limited | provider_accepted | provider_rejected | delivery_unknown;

observed_ai_referral, qualified outcome. No PII into analytics. No lead database.

10 SECURITY, CACHING, RELEASE: nginx root = dist/site only; one production HTTPS origin; one trailing-slash policy; explicit redirects;
